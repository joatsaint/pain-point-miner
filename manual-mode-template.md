# Manual Mode — paste your own transcript (and comments), no code, no API key

Copy this template into a new file, fill it in, save it as
`transcripts/<any-group-name>/<any-channel-name>/anything.md`, then ask
your AI to read that file and give you the top questions, pain points, and
desired outcomes it finds — same output Pain Point Miner's automated
version produces, with nothing installed and nothing metered.

Get the transcript from YouTube's own "Show transcript" button under a
video. Comments are optional — copy a handful of the real ones if you want
them included; skip that section entirely if you don't.

---

```
# Video Title Here

**Channel:** Channel Name
**URL:** https://www.youtube.com/watch?v=VIDEO_ID

---

## Transcript

Paste the transcript text here.

## Comments (optional — delete this section if skipping)

Paste a handful of real audience comments here, one per line.
```

---

Once the file's saved, just tell your AI something like: "Read
`transcripts/<group>/<channel>/anything.md` and give me the top questions,
pain points, and desired outcomes the audience is expressing, ranked by
how often they come up." That's the whole thing.
